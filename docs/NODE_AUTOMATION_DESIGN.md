# Node Automation Design

**Goal:** Make local node setup as easy as possible to minimize user errors.

---

## Commands Overview

```bash
# Check system requirements
cryptofolio node check-requirements

# Install and configure a node
cryptofolio node install bitcoin [--pruned] [--testnet]

# Check node status
cryptofolio node status [bitcoin|ethereum|all]

# Manage nodes
cryptofolio node start bitcoin
cryptofolio node stop bitcoin
cryptofolio node restart bitcoin

# Remove node (keeps data)
cryptofolio node remove bitcoin

# Uninstall completely (deletes data)
cryptofolio node uninstall bitcoin --confirm
```

## Implementation: `cryptofolio node install bitcoin`

### What It Does

1. **Check requirements**
   - Disk space (10GB pruned, 500GB full)
   - macOS version
   - Homebrew installed

2. **Install Bitcoin Core**
   - Via Homebrew: `brew install bitcoin`
   - Or download from bitcoin.org

3. **Generate secure RPC password**
   - Random 32-character password
   - Store in macOS Keychain

4. **Create configuration**
   - Generate `bitcoin.conf` with secure defaults
   - Pruned mode by default (10GB)
   - RPC enabled for Cryptofolio

5. **Start node**
   - Launch bitcoind as background service
   - Register with launchd (auto-start on boot)

6. **Configure Cryptofolio**
   - Save RPC credentials to Keychain
   - Set as default Bitcoin node

7. **Monitor sync**
   - Show progress bar
   - Estimate time remaining
   - Allow using public APIs while syncing

### Code Structure

```rust
// src/cli/commands/node.rs

pub async fn handle_node_install(
    blockchain: Blockchain,
    opts: NodeInstallOptions,
) -> Result<()> {
    match blockchain {
        Blockchain::Bitcoin => install_bitcoin_core(opts).await?,
        Blockchain::Ethereum => install_geth(opts).await?,
        _ => return Err("Installation not supported for this blockchain"),
    }
    Ok(())
}

async fn install_bitcoin_core(opts: NodeInstallOptions) -> Result<()> {
    // 1. Check requirements
    check_disk_space(if opts.pruned { 10_000 } else { 500_000 })?;
    check_homebrew_installed()?;

    // 2. Install Bitcoin Core
    info("Installing Bitcoin Core via Homebrew...");
    run_command("brew", &["install", "bitcoin"])?;

    // 3. Generate RPC password
    let rpc_password = generate_secure_password(32);
    keychain::store("bitcoin.rpc_password", &rpc_password)?;

    // 4. Create config
    let config_dir = dirs::home_dir()
        .unwrap()
        .join("Library/Application Support/Bitcoin");
    fs::create_dir_all(&config_dir)?;

    let config_path = config_dir.join("bitcoin.conf");
    let config = if opts.pruned {
        BITCOIN_CONFIG_PRUNED_TEMPLATE
    } else {
        BITCOIN_CONFIG_FULL_TEMPLATE
    };

    fs::write(&config_path, config.replace("{{RPC_PASSWORD}}", &rpc_password))?;

    // 5. Start as service
    create_launchd_service("bitcoin")?;
    run_command("launchctl", &["start", "org.bitcoin.bitcoind"])?;

    // 6. Configure Cryptofolio
    let node_repo = BlockchainNodeRepository::new(pool);
    node_repo.upsert(BlockchainNode {
        blockchain: "bitcoin".to_string(),
        node_type: "local".to_string(),
        rpc_url: Some("http://localhost:8332".to_string()),
        api_key: None,
        is_default: true,
        ..Default::default()
    }).await?;

    // 7. Show sync status
    success("Bitcoin Core installed successfully!");
    info("Initial blockchain sync will take 1-2 days.");
    info("You can use public APIs while syncing:");
    println!();
    println!("  cryptofolio wallet sync --provider blockchain.info");
    println!();
    println!("Check sync progress:");
    println!("  cryptofolio node status bitcoin");

    Ok(())
}

fn create_launchd_service(service: &str) -> Result<()> {
    let plist = match service {
        "bitcoin" => BITCOIN_LAUNCHD_PLIST,
        "ethereum" => ETHEREUM_LAUNCHD_PLIST,
        _ => return Err("Unknown service"),
    };

    let home = dirs::home_dir().unwrap();
    let plist_dir = home.join("Library/LaunchAgents");
    fs::create_dir_all(&plist_dir)?;

    let plist_path = plist_dir.join(format!("org.{}.{}.plist", service, service));
    fs::write(plist_path, plist)?;

    Ok(())
}
```

const BITCOIN_CONFIG_PRUNED_TEMPLATE: &str = r#"
# Bitcoin Core Configuration (Generated by Cryptofolio)
# Location: ~/Library/Application Support/Bitcoin/bitcoin.conf

# Run as daemon
daemon=1

# Pruned mode (saves disk space - only 10GB)
prune=10000

# RPC settings for Cryptofolio
server=1
rpcuser=cryptofolio
rpcpassword={{RPC_PASSWORD}}
rpcallowip=127.0.0.1
rpcport=8332

# Network settings (optimize for MacBook)
listen=0
maxconnections=16
dbcache=450

# Disable wallet (we only read blockchain)

printtoconsole=0

## Fallback Strategy

### Automatic Fallback

```rust
// If local node is not available, fall back to public API automatically
pub async fn get_bitcoin_client(pool: &SqlitePool) -> Result<Box<dyn BlockchainReader>> {
    let node_repo = BlockchainNodeRepository::new(pool);

    // Try local node first
    if let Some(node) = node_repo.get_default("bitcoin").await? {
        if node.node_type == "local" {
            match BitcoinCoreClient::new(&node.rpc_url.unwrap()).await {
                Ok(client) => {
                    if client.health_check().await.is_ok() {
                        return Ok(Box::new(client));
                    }
                }
                Err(_) => {
                    warning("Local Bitcoin node unavailable, using public API");
                }
            }
        }
    }

    // Fall back to public API
    Ok(Box::new(BlockchainInfoClient::new()))
}
```
