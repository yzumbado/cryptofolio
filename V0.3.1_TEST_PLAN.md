# Cryptofolio v0.3.1 Test Plan
## Native Touch ID Integration

**Version:** 0.3.1
**Date:** 2026-02-21
**Status:** Ready for Testing

---

## Overview

v0.3.1 implements native Touch ID prompts using FFI bindings to macOS Security Framework. This completes the Touch ID integration started in v0.3.0.

**What's New:**
- Native Touch ID authentication prompts
- Three security levels with actual enforcement (Standard, Touch ID Protected, Touch ID Only)
- Proper access control using SecAccessControl API
- Session caching to minimize Touch ID prompts

**Technical Implementation:**
- Created `src/config/keychain_ffi.rs` with direct FFI to Security.framework
- Updated `src/config/keychain_macos.rs` to use FFI for Touch ID levels
- All unit tests passing (3/3 FFI tests)
- Release build successful

---

## Prerequisites

- **Hardware:** Mac with Touch ID sensor (MacBook Pro 2016+ or MacBook Air 2018+)
- **OS:** macOS 10.12.2+ (Sierra or later)
- **Build:** v0.3.1 release binary (`./target/release/cryptofolio`)
- **Existing Data:** Secrets migrated to keychain from v0.3.0

### Test 8: Upgrade Security Level

**Objective:** Verify security level upgrade with re-authentication

**Steps:**
```bash
# Check current security level
./target/release/cryptofolio config keychain-status | grep binance.api_secret

# Upgrade to Touch ID Only
./target/release/cryptofolio config upgrade-security binance.api_secret --to touchid-only
```

**Expected:**
- Touch ID prompt appears for **current** access (to read existing secret)
- Secret re-stored with new security level (Touch ID Only)
- Touch ID prompt appears again for **new** access control
- Keychain status shows updated security level

**Success Criteria:**
- ✅ Two Touch ID prompts (read old + write new)
- ✅ Security level upgraded successfully
- ✅ No data loss during upgrade
