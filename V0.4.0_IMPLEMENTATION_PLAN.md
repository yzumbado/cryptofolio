# Cryptofolio v0.4.0 - Binance Deep Integration

**Goal:** Complete transaction history sync from Binance for accurate portfolio tracking

**User Need:** "I buy crypto on Binance and need exact tracking of all my money movements"

---

## Current State

### What We Have ✅
- Basic sync: `cryptofolio sync` fetches current balances
- BinanceClient with account endpoint
- Read-only API key support
- Testnet support

### What We're Missing ❌
- Trade history (buy/sell records)
- Deposit history (fiat → crypto, crypto deposits)
- Withdrawal history (crypto → external wallet)
- Fee tracking per transaction
- Historical backfill
- Automatic transaction creation

---

## User Requirements

### Primary Goal
**"When I sync Binance, I want all my trades, deposits, and withdrawals automatically imported as transactions with accurate P&L tracking"**

### Specific Needs

1. **Trade History Import**
   - All spot trades (BTC/USDT, ETH/USDT, etc.)
   - Buy and sell transactions
   - Exact prices and quantities
   - Trading fees
   - Date/time of each trade

2. **Deposit History**
   - Crypto deposits from external wallets
   - Fiat deposits (if using Binance fiat on-ramp)
   - Deposit amounts and fees
   - Deposit status (completed, pending, failed)

3. **Withdrawal History**
   - Crypto withdrawals to external wallets
   - Withdrawal amounts and network fees
   - Destination addresses (for reference)
   - Withdrawal status

4. **Automatic Reconciliation**
   - Detect duplicate imports
   - Update existing transactions
   - Handle partial imports
   - Preserve manual transactions

5. **P&L Integration**
   - Trades create tax lots automatically
   - Deposits don't affect P&L (not a purchase)
   - Withdrawals preserve cost basis
   - Fees tracked accurately

### Data Flow

```
User Command: cryptofolio sync-history --account Binance

    ↓

1. SyncOrchestrator
   - Load sync state (last sync times)
   - Determine what to fetch (incremental vs full)

    ↓

2. BinanceClient
   - Fetch trades since last sync
   - Fetch deposits since last sync
   - Fetch withdrawals since last sync
   - Handle pagination (1000 per request limit)

    ↓

3. TransactionImporter
   - Convert Binance trades → Cryptofolio transactions
   - Convert deposits → transfer_in transactions
   - Convert withdrawals → transfer_out transactions
   - Detect duplicates (external_id)
   - Calculate fees

    ↓

4. PnLCalculator
   - Process trades (create tax lots, calculate P&L)
   - Skip deposits/withdrawals for P&L

    ↓

5. SyncStateRepository
   - Update last sync times
   - Save progress
```

**Key Logic:**

**Trade Import:**
```rust
async fn import_trade(&self, account_id: &str, trade: &BinanceTrade) -> Result<ImportResult> {
    // Check if already imported
    let external_id = format!("binance-trade-{}", trade.id);
    if self.is_duplicate(&external_id).await? {
        return Ok(ImportResult::Skipped("Duplicate".into()));
    }

    // Parse symbol (BTCUSDT → BTC + USDT)
    let (base, quote) = self.parse_symbol(&trade.symbol)?;

    let timestamp = DateTime::from_timestamp_millis(trade.time)
        .ok_or_else(|| CryptofolioError::InvalidInput("Invalid timestamp".into()))?;

    let price = Decimal::from_str(&trade.price)?;
    let qty = Decimal::from_str(&trade.qty)?;
    let commission = Decimal::from_str(&trade.commission)?;

    // Create transaction (buy or sell based on is_buyer)
    let mut tx = if trade.is_buyer {
        // Buying base asset with quote asset
        Transaction::new_buy(account_id, &base, qty, price, timestamp)
    } else {
        // Selling base asset for quote asset
        Transaction::new_sell(account_id, &base, qty, price, timestamp)
    };

    tx.external_id = Some(external_id);
    tx.fee = Some(commission);
    tx.fee_asset = Some(trade.commission_asset.clone());
    tx.notes = Some(format!("Imported from Binance (Order #{})", trade.order_id));

    let tx_id = self.tx_repo.insert(&tx).await?;

    // Process P&L
    let method = CostBasisMethod::Fifo;
    if trade.is_buyer {
        self.pnl_calc.process_acquisition(tx_id, account_id, &base, qty, price, timestamp, method).await?;
    } else {
        self.pnl_calc.process_disposal(tx_id, account_id, &base, qty, price, timestamp, method).await?;
    }

    Ok(ImportResult::Created(tx_id))
}
```

## Edge Cases & Error Handling

### 1. Rate Limiting
**Issue:** Binance API has rate limits (1200 requests/minute for authenticated)

**Solution:**
- Implement exponential backoff
- Track request count
- Add delays between paginated requests
- Show progress bar to user

### 2. Large History
**Issue:** User might have 10,000+ trades

**Solution:**
- Pagination (1000 trades per request)
- Progress bar with estimated time
- Ability to pause/resume (via sync state)
- Batch database inserts

### 3. Symbol Parsing
**Issue:** Trading pairs like "BTCUSDT" need parsing

**Solution:**
- Use Binance exchangeInfo API to get all symbols
- Cache symbol info
- Handle special cases (e.g., "123456" token with numbers)

### 4. Duplicates
**Issue:** Re-running sync shouldn't create duplicates

**Solution:**
- Use external_id field (binance-trade-12345)
- Check before inserting
- Update if status changed

### 5. Failed Transactions
**Issue:** Deposits/withdrawals can fail

**Solution:**
- Only import completed transactions (status = 1 or 6)
- Add notes about status
- Provide flag to include all statuses

### 6. Fees in Different Assets
**Issue:** Trading fee might be in BNB, BTC, or quote asset

**Solution:**
- Store fee and fee_asset separately
- Handle fee conversion for P&L if needed
- Document fee handling in reports
