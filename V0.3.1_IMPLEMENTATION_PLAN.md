# v0.3.1 Implementation Plan - Native Touch ID Prompts

**Goal:** Complete Touch ID integration using FFI to macOS Security Framework
**Estimated Time:** 2-3 days
**Status:** Ready to start

---

## Overview

### What We're Building

Add native macOS Touch ID authentication prompts when accessing secrets with `touchid` or `touchid-only` security levels.

**Current State (v0.3.0):**
```bash
$ cryptofolio sync --account Binance
# Secret retrieved silently from keychain
Syncing with Binance...
```

**Target State (v0.3.1):**
```bash
$ cryptofolio sync --account Binance
# Native macOS Touch ID prompt appears
🔐 Touch ID Required
   Cryptofolio needs to access "binance.api_secret"
   👆 Touch the sensor to continue...

# After authentication
Syncing with Binance...
```

### Why FFI?

The Rust `security-framework` crate doesn't expose `SecAccessControl` APIs needed for Touch ID. We'll use FFI (Foreign Function Interface) to call macOS Security Framework directly.

```rust
//! FFI bindings to macOS Security Framework for Touch ID support
//!
//! This module provides low-level FFI bindings to macOS Security Framework APIs
//! that aren't exposed by the security-framework Rust crate.

#![allow(non_upper_case_globals)]
#![allow(non_camel_case_types)]
#![allow(dead_code)]

use std::os::raw::{c_void, c_char, c_int};
use std::ptr;

// ============================================================================
// Core Foundation Types
// ============================================================================

type CFTypeRef = *const c_void;
type CFStringRef = *const c_void;
type CFDictionaryRef = *const c_void;
type CFAllocatorRef = *const c_void;
type CFErrorRef = *const c_void;

// ============================================================================
// Security Framework Types
// ============================================================================

type SecAccessControlRef = *const c_void;
type OSStatus = i32;

// ============================================================================
// Constants
// ============================================================================

// Access Control Flags
const kSecAccessControlUserPresence: u64 = 1 << 0;
const kSecAccessControlBiometryAny: u64 = 1 << 1;
const kSecAccessControlBiometryCurrentSet: u64 = 1 << 3;

// Protection Classes
// These will be defined as CFStringRef constants via extern

// OSStatus codes
const errSecSuccess: OSStatus = 0;
const errSecUserCanceled: OSStatus = -128;
const errSecAuthFailed: OSStatus = -25293;
const errSecItemNotFound: OSStatus = -25300;

// ============================================================================
// External C Functions
// ============================================================================

#[link(name = "Security", kind = "framework")]
extern "C" {
    fn SecAccessControlCreateWithFlags(
        allocator: CFAllocatorRef,
        protection: CFTypeRef,
        flags: u64,
        error: *mut CFErrorRef,
    ) -> SecAccessControlRef;

    fn SecItemAdd(
        attributes: CFDictionaryRef,
        result: *mut CFTypeRef,
    ) -> OSStatus;

    fn SecItemCopyMatching(
        query: CFDictionaryRef,
        result: *mut CFTypeRef,
    ) -> OSStatus;

    fn SecItemUpdate(
        query: CFDictionaryRef,
        attributes_to_update: CFDictionaryRef,
    ) -> OSStatus;

    fn SecItemDelete(query: CFDictionaryRef) -> OSStatus;
}

#[link(name = "CoreFoundation", kind = "framework")]
extern "C" {
    fn CFRelease(cf: CFTypeRef);
    fn CFRetain(cf: CFTypeRef) -> CFTypeRef;

    // String operations
    fn CFStringCreateWithCString(
        allocator: CFAllocatorRef,
        cstr: *const c_char,
        encoding: u32,
    ) -> CFStringRef;

    // Dictionary operations
    fn CFDictionaryCreate(
        allocator: CFAllocatorRef,
        keys: *const CFTypeRef,
        values: *const CFTypeRef,
        num_values: isize,
        key_callbacks: *const c_void,
        value_callbacks: *const c_void,
    ) -> CFDictionaryRef;

    // Error handling
    fn CFErrorGetCode(err: CFErrorRef) -> isize;
}

// Constants from Security.framework
extern "C" {
    static kSecAttrAccessibleWhenUnlockedThisDeviceOnly: CFStringRef;
    static kSecClass: CFStringRef;
    static kSecClassGenericPassword: CFStringRef;
    static kSecAttrService: CFStringRef;
    static kSecAttrAccount: CFStringRef;
    static kSecValueData: CFStringRef;
    static kSecReturnData: CFStringRef;
    static kSecAttrAccessControl: CFStringRef;
    static kSecUseOperationPrompt: CFStringRef;
}

// ============================================================================
// Safe Rust Wrappers
// ============================================================================

pub struct AccessControl {
    inner: SecAccessControlRef,
}

impl AccessControl {
    pub fn new(flags: u64) -> Result<Self, String> {
        unsafe {
            let mut error: CFErrorRef = ptr::null_mut();

            let access_control = SecAccessControlCreateWithFlags(
                ptr::null(),
                kSecAttrAccessibleWhenUnlockedThisDeviceOnly,
                flags,
                &mut error,
            );

            if access_control.is_null() {
                if !error.is_null() {
                    let code = CFErrorGetCode(error);
                    CFRelease(error as CFTypeRef);
                    return Err(format!("Failed to create access control: {}", code));
                }
                return Err("Failed to create access control".to_string());
            }

            Ok(Self { inner: access_control })
        }
    }

    pub fn as_ptr(&self) -> SecAccessControlRef {
        self.inner
    }
}

impl Drop for AccessControl {
    fn drop(&mut self) {
        if !self.inner.is_null() {
            unsafe { CFRelease(self.inner as CFTypeRef) };
        }
    }
}
```

#### Task 1.2: Implement `add_generic_password_with_access_control`

**Function:** Create keychain item with Touch ID access control

```rust
pub fn add_generic_password_with_access_control(
    service: &str,
    account: &str,
    password: &[u8],
    flags: u64,
    _prompt: &str, // Stored for later use
) -> Result<(), String> {
    unsafe {
        // Create access control
        let access_control = AccessControl::new(flags)?;

        // Convert strings to CFString
        let service_cf = CFStringCreateWithCString(
            ptr::null(),
            service.as_ptr() as *const c_char,
            0x08000100, // kCFStringEncodingUTF8
        );
        let account_cf = CFStringCreateWithCString(
            ptr::null(),
            account.as_ptr() as *const c_char,
            0x08000100,
        );

        // Create password data
        let data_cf = CFDataCreate(
            ptr::null(),
            password.as_ptr(),
            password.len() as isize,
        );

        // Build attributes dictionary
        let keys = [
            kSecClass,
            kSecAttrService,
            kSecAttrAccount,
            kSecValueData,
            kSecAttrAccessControl,
        ];
        let values = [
            kSecClassGenericPassword,
            service_cf as CFTypeRef,
            account_cf as CFTypeRef,
            data_cf as CFTypeRef,
            access_control.as_ptr() as CFTypeRef,
        ];

        let dict = CFDictionaryCreate(
            ptr::null(),
            keys.as_ptr(),
            values.as_ptr(),
            5,
            ptr::null(),
            ptr::null(),
        );

        // Add to keychain
        let status = SecItemAdd(dict, ptr::null_mut());

        // Cleanup
        CFRelease(service_cf);
        CFRelease(account_cf);
        CFRelease(data_cf as CFTypeRef);
        CFRelease(dict as CFTypeRef);

        if status == errSecSuccess {
            Ok(())
        } else {
            Err(format!("Failed to add keychain item: {}", status))
        }
    }
}
```

#### Task 1.3: Implement `get_generic_password_with_prompt`

**Function:** Retrieve keychain item (triggers Touch ID prompt)

```rust
pub fn get_generic_password_with_prompt(
    service: &str,
    account: &str,
    prompt: &str,
) -> Result<Vec<u8>, String> {
    unsafe {
        // Convert strings to CFString
        let service_cf = CFStringCreateWithCString(
            ptr::null(),
            service.as_ptr() as *const c_char,
            0x08000100,
        );
        let account_cf = CFStringCreateWithCString(
            ptr::null(),
            account.as_ptr() as *const c_char,
            0x08000100,
        );
        let prompt_cf = CFStringCreateWithCString(
            ptr::null(),
            prompt.as_ptr() as *const c_char,
            0x08000100,
        );

        // Build query dictionary
        let keys = [
            kSecClass,
            kSecAttrService,
            kSecAttrAccount,
            kSecReturnData,
            kSecUseOperationPrompt, // This triggers the Touch ID prompt!
        ];
        let values = [
            kSecClassGenericPassword,
            service_cf as CFTypeRef,
            account_cf as CFTypeRef,
            kCFBooleanTrue as CFTypeRef,
            prompt_cf as CFTypeRef,
        ];

        let query = CFDictionaryCreate(
            ptr::null(),
            keys.as_ptr(),
            values.as_ptr(),
            5,
            ptr::null(),
            ptr::null(),
        );

        let mut result: CFTypeRef = ptr::null();
        let status = SecItemCopyMatching(query, &mut result);

        // Cleanup
        CFRelease(service_cf);
        CFRelease(account_cf);
        CFRelease(prompt_cf);
        CFRelease(query as CFTypeRef);

        match status {
            errSecSuccess => {
                // Extract bytes from CFData
                let data = extract_data_from_cf(result)?;
                CFRelease(result);
                Ok(data)
            }
            errSecUserCanceled => {
                Err("User cancelled Touch ID authentication".to_string())
            }
            errSecAuthFailed => {
                Err("Touch ID authentication failed".to_string())
            }
            errSecItemNotFound => {
                Err("Secret not found in keychain".to_string())
            }
            _ => {
                Err(format!("Keychain error: {}", status))
            }
        }
    }
}
```

#### Task 1.4: Implement `update_access_control`

**Function:** Update existing item's access control

```rust
pub fn update_access_control(
    service: &str,
    account: &str,
    flags: u64,
) -> Result<(), String> {
    unsafe {
        // Create new access control
        let access_control = AccessControl::new(flags)?;

        // Build query
        let service_cf = CFStringCreateWithCString(
            ptr::null(),
            service.as_ptr() as *const c_char,
            0x08000100,
        );
        let account_cf = CFStringCreateWithCString(
            ptr::null(),
            account.as_ptr() as *const c_char,
            0x08000100,
        );

        let query_keys = [
            kSecClass,
            kSecAttrService,
            kSecAttrAccount,
        ];
        let query_values = [
            kSecClassGenericPassword,
            service_cf as CFTypeRef,
            account_cf as CFTypeRef,
        ];
        let query = CFDictionaryCreate(
            ptr::null(),
            query_keys.as_ptr(),
            query_values.as_ptr(),
            3,
            ptr::null(),
            ptr::null(),
        );

        // Build update attributes
        let update_keys = [kSecAttrAccessControl];
        let update_values = [access_control.as_ptr() as CFTypeRef];
        let update_dict = CFDictionaryCreate(
            ptr::null(),
            update_keys.as_ptr(),
            update_values.as_ptr(),
            1,
            ptr::null(),
            ptr::null(),
        );

        let status = SecItemUpdate(query, update_dict);

        // Cleanup
        CFRelease(service_cf);
        CFRelease(account_cf);
        CFRelease(query as CFTypeRef);
        CFRelease(update_dict as CFTypeRef);

        if status == errSecSuccess {
            Ok(())
        } else {
            Err(format!("Failed to update access control: {}", status))
        }
    }
}
```

```rust
use super::keychain_ffi;

fn store_with_security(
    &self,
    key: &str,
    secret: &str,
    level: KeychainSecurityLevel,
) -> Result<()> {
    match level {
        KeychainSecurityLevel::Standard => {
            // Use existing high-level API
            set_generic_password(SERVICE_NAME, key, secret.as_bytes())
                .map_err(|e| CryptofolioError::Keychain(e.to_string()))?;
        }
        KeychainSecurityLevel::TouchIdProtected => {
            // Use FFI with Touch ID OR password
            keychain_ffi::add_generic_password_with_access_control(
                SERVICE_NAME,
                key,
                secret.as_bytes(),
                keychain_ffi::kSecAccessControlUserPresence,
                &format!("Cryptofolio needs to access '{}'", key),
            )
            .map_err(|e| CryptofolioError::Keychain(e))?;
        }
        KeychainSecurityLevel::TouchIdOnly => {
            // Use FFI with Touch ID only (no password fallback)
            keychain_ffi::add_generic_password_with_access_control(
                SERVICE_NAME,
                key,
                secret.as_bytes(),
                keychain_ffi::kSecAccessControlBiometryCurrentSet,
                &format!("Cryptofolio needs to access '{}'", key),
            )
            .map_err(|e| CryptofolioError::Keychain(e))?;
        }
    }
    Ok(())
}
```

```rust
fn retrieve(&self, key: &str) -> Result<String> {
    // Check cache first (avoid Touch ID on every call)
    if let Some(cached) = self.get_cached(key) {
        return Ok(cached);
    }

    // Try FFI retrieval with prompt (triggers Touch ID if configured)
    let data = match keychain_ffi::get_generic_password_with_prompt(
        SERVICE_NAME,
        key,
        &format!("Cryptofolio needs to access '{}'", key),
    ) {
        Ok(data) => data,
        Err(e) if e.contains("not found") => {
            // Fallback to standard retrieval (for Standard level items)
            get_generic_password(SERVICE_NAME, key)
                .map_err(|e| CryptofolioError::Keychain(e.to_string()))?
                .to_vec()
        }
        Err(e) if e.contains("cancelled") => {
            return Err(CryptofolioError::KeychainAuthCancelled(e));
        }
        Err(e) if e.contains("failed") => {
            return Err(CryptofolioError::TouchIdAuthFailed(e));
        }
        Err(e) => {
            return Err(CryptofolioError::Keychain(e));
        }
    };

    let value = String::from_utf8(data)
        .map_err(|e| CryptofolioError::Keychain(e.to_string()))?;

    // Cache for 15 minutes
    self.cache_value(key, &value);
    Ok(value)
}
```

```rust
pub fn upgrade_security_level(
    &self,
    key: &str,
    new_level: KeychainSecurityLevel,
) -> Result<()> {
    // First, retrieve the current secret
    let secret = self.retrieve(key)?;

    // Delete the old item
    delete_generic_password(SERVICE_NAME, key)
        .map_err(|e| CryptofolioError::Keychain(e.to_string()))?;

    // Store with new security level (uses FFI if touchid/touchid-only)
    self.store_with_security(key, &secret, new_level)?;

    Ok(())
}
```
