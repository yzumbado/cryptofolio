## 🏗️ Architecture

### Database Schema

```sql
-- MIGRATION_007: Wallet addresses and blockchain sync
CREATE TABLE wallet_addresses (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    account_id TEXT NOT NULL REFERENCES accounts(id),
    blockchain TEXT NOT NULL,  -- 'bitcoin', 'ethereum', 'solana', 'cardano'
    address TEXT NOT NULL,
    address_type TEXT,         -- 'legacy', 'segwit', 'native_segwit', 'erc20', etc.
    label TEXT,
    xpub TEXT,                 -- For HD wallets (BTC)
    derivation_path TEXT,      -- e.g., "m/84'/0'/0'"
    last_synced_at DATETIME,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(blockchain, address)
);

CREATE TABLE blockchain_sync_state (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    wallet_address_id INTEGER NOT NULL REFERENCES wallet_addresses(id),
    last_block_height INTEGER,
    last_tx_hash TEXT,
    last_synced_at DATETIME,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Store blockchain node configurations
CREATE TABLE blockchain_nodes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    blockchain TEXT NOT NULL UNIQUE,
    node_type TEXT NOT NULL,   -- 'local', 'public_api', 'custom'
    rpc_url TEXT,
    api_key TEXT,              -- For public APIs
    is_default BOOLEAN DEFAULT FALSE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_wallet_addresses_account ON wallet_addresses(account_id);
CREATE INDEX idx_wallet_addresses_blockchain ON wallet_addresses(blockchain);
```

### BlockchainReader Trait

```rust
#[async_trait]
pub trait BlockchainReader: Send + Sync {
    /// Get current balance for an address
    async fn get_balance(&self, address: &str) -> Result<Decimal>;

    /// Get transaction history for an address
    async fn get_transactions(
        &self,
        address: &str,
        start_block: Option<u64>,
        end_block: Option<u64>
    ) -> Result<Vec<BlockchainTransaction>>;

    /// Get token balances (for chains that support tokens)
    async fn get_token_balances(&self, address: &str) -> Result<Vec<TokenBalance>>;

    /// Check if node is available and synced
    async fn health_check(&self) -> Result<NodeHealth>;
}
```

## 🔧 CLI Commands

### Wallet Management

```bash
# Add Bitcoin address (single address)
cryptofolio wallet add "My Ledger" \
  --blockchain bitcoin \
  --address bc1q...xyz \
  --label "Cold storage"

# Add Bitcoin xpub (HD wallet for Sparrow)
cryptofolio wallet add "Sparrow Wallet" \
  --blockchain bitcoin \
  --xpub zpub... \
  --derivation-path "m/84'/0'/0'"

# Add Ethereum address
cryptofolio wallet add "MetaMask Main" \
  --blockchain ethereum \
  --address 0x...abc

# Add Solana address
cryptofolio wallet add "Solflare" \
  --blockchain solana \
  --address ABC...xyz

# Add Cardano address
cryptofolio wallet add "Eternl" \
  --blockchain cardano \
  --address addr1...

# List all wallets
cryptofolio wallet list

# Show wallet details
cryptofolio wallet show "My Ledger"

# Sync wallet from blockchain
cryptofolio wallet sync "My Ledger"
# ✓ Synced BTC balance: 0.5000
# ✓ Imported 23 transactions

# Sync all wallets
cryptofolio wallet sync --all
```

### Audit

```bash
# Quick audit summary
cryptofolio audit

# Detailed audit report
cryptofolio audit --detailed

# Audit specific asset
cryptofolio audit --asset BTC

# Export audit report
cryptofolio audit --export audit-2026-03-19.txt
```

### Node Configuration

```bash
# Configure Bitcoin Core local node
cryptofolio node set bitcoin \
  --type local \
  --rpc-url http://localhost:8332 \
  --rpc-user bitcoin \
  --rpc-password <password>

# Configure Ethereum Geth node
cryptofolio node set ethereum \
  --type local \
  --rpc-url http://localhost:8545

# Use public API (fallback)
cryptofolio node set ethereum \
  --type public_api \
  --rpc-url https://eth-mainnet.g.alchemy.com/v2/<key> \
  --api-key <key>

# Check node status
cryptofolio node status
# Bitcoin:  ✓ Local node (height: 835,421, synced)
# Ethereum: ✓ Local node (height: 19,234,567, synced)
# Solana:   ⚠️ Public API (rate limited)
# Cardano:  ✗ Not configured
```

## 🔐 Privacy & Security

### Local Node Support

**Bitcoin:**
- Primary: Bitcoin Core RPC
- Fallback: Blockchain.info API

**Ethereum:**
- Primary: Geth/Erigon RPC
- Fallback: Etherscan API (requires API key)

**Solana:**
- Primary: Local validator node (rare)
- Fallback: Public RPC (Solana Foundation, Helius)

**Cardano:**
- Primary: cardano-node
- Fallback: Blockfrost API (requires API key)

### Privacy Modes

```bash
# Strict privacy (local nodes only)
cryptofolio config set privacy.mode strict
# Will error if local node not available

# Balanced (prefer local, fallback to public)
cryptofolio config set privacy.mode balanced  # Default

# Convenience (public APIs OK)
cryptofolio config set privacy.mode convenience
```

### API Key Storage

All API keys stored in macOS Keychain (existing v0.3.1 feature)

```bash
cryptofolio config set-secret etherscan.api_key
cryptofolio config set-secret blockfrost.project_id
```
