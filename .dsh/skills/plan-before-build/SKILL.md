# Plan before build

For medium-to-large work, present a plan and get sign-off BEFORE writing:

1. **Connecting idea** — one or two sentences: what and why.
2. **Artifact table** — every file involved, marked new / change / remove.
3. **Deliberate non-goals** — what you are explicitly not doing (stops scope creep).
4. **Choices for Yoel** — the decisions only he can make, each with your
   recommendation, stated plainly.
5. **Sign-off** — do not write code or docs until Yoel confirms. Small edits
   skip this skill.

Then execute, verify the mechanisms fired, and close with the
`working-discipline` end ritual.
