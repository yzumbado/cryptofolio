## Technical Journey - What We Learned

### Issue #1: SIGBUS on Symbol Access

**Problem:** Declaring `kSecAttrAccessibleWhenUnlocked` as `extern static CFTypeRef` caused SIGBUS.

**Root Cause:** The symbol is actually `CFStringRef`, not `CFTypeRef`, and static linking was failing.

**Solution:** Changed to `extern static CFStringRef` but still crashed.

### Issue #2: SIGKILL on Startup

**Problem:** Process killed immediately, even for `--version`.

**Root Cause:** Extern static still not working correctly with dynamic linker.

**Solution:** Switched to **runtime symbol loading via dlsym**:
```rust
let sym_ptr = dlsym(RTLD_DEFAULT, symbol_name);
let value = *(sym_ptr as *const CFStringRef);
```

This completely solved the symbol loading issues.

### Issue #3: OSStatus -34018 (errSecMissingEntitlement)

**Problem:** `SecItemAdd` fails with -34018 when using `SecAccessControl`.

**Root Cause:** macOS security policy - ad-hoc signing cannot use Touch ID.

**Discovery:** Debug logs showed FFI working perfectly:
```
[DEBUG] create_access_control: SecAccessControlCreateWithFlags returned
Warning: Failed to store in keychain: OSStatus -34018
Falling back to TOML storage...
```

**Conclusion:** **Code is correct**. macOS requires:
- Real code signing certificate (not ad-hoc)
- Proper entitlements
- Either self-signed cert OR Apple Developer ID

### Issue #4: Binary Corruption After Signing

**Problem:** After signing with self-signed cert, all commands killed.

**Root Cause:** Signature + build artifacts conflict.

**Solution:** `cargo clean` and rebuild. Always rebuild after changing signature.

## Known Limitations

### Platform

- ⚠️ **macOS only** - Linux/Windows support planned (different keychain APIs)
- ⚠️ **macOS 10.12.2+** - Requires Sierra or later
- ⚠️ **Touch ID hardware** - Biometric levels need physical sensor

### Signing

- ⚠️ **Ad-hoc signing insufficient** - Gets OSStatus -34018
- ⚠️ **Self-signed cert needed** - For Touch ID testing
- ⚠️ **Apple Developer ID needed** - For public distribution

### Debug Mode

- ⚠️ **Verbose logging** - eprintln! in production paths
- ⚠️ **Performance impact** - Logging adds ~1-2ms overhead
- ⚠️ **User-visible output** - Debug messages shown to users

**Plan:** Remove debug logging before v0.3.1 release
